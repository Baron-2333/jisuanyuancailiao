# Minecraft 配方计算器

一款在线 Minecraft 工业配方材料需求计算工具，帮助玩家快速计算合成目标物品所需的原材料数量。

**在线访问**: https://baron-2333.github.io/yuancailiao

## 功能特性

### 1. 配方计算
- 输入目标物品及其数量，自动计算所需原材料
- 支持多物品同时计算
- 可选择是否开启"仅显示原材料"模式
- 支持导出计算结果为 CSV 文件

### 2. 物品管理
- 添加、编辑、删除物品
- 设置物品为"原材料"（开启后不会被继续拆解）
- 搜索筛选物品

### 3. 配方管理
- 添加、编辑、删除配方
- 输入配方名称和产出数量
- 添加多个原材料（1-9个）
- 自动创建物品（输入名称即可）

### 4. 历史记录
- 自动保存计算历史
- 支持一键重新计算
- 清空历史记录

## 使用示例

### 计算木板 x8 需要多少原木？

1. **添加物品**
   - 进入"物品管理"，添加"原木"，开启"原材料"开关

2. **添加配方**
   - 进入"配方管理"，添加配方：
     - 产出物品：`木板`，产出数量：`4`
     - 原材料：`原木` × `1`

3. **计算**
   - 进入"配方计算"，选择"木板"，数量 `8`
   - 点击计算 → 得到 **原木 × 2**
