# 原材料计算器

工业配方材料需求计算系统 v0.0.37
代码 100% 由 AI 生成。(包括这份README.md)

## 功能概览

### 1. 配方计算（核心功能）

快速计算制作指定物品所需的原材料需求。

**使用方法**：
1. 选择要制作的物品（如：冲压机）
2. 输入数量
3. 点击「展开子配方」开关控制是否显示配方层级
4. 点击「计算总需求」查看最终原材料统计

**显示说明**：
- **材料**：配方所需材料名称
- **单个需求**：制作1个成品所需的材料数量
- **总需求**：根据输入数量计算的总材料需求
- **溯源信息**：有溯源配置时显示，如 `9 (包含 1)` 表示需要9个原材料，包含1个中间产物

### 2. 原材料管理

管理基础材料（铁锭、铜锭、煤矿等）。

**功能**：
- 添加新原材料（名称、单位、数量）
- 编辑现有原材料
- 删除不需要的原材料
- 支持导出为CSV文件

### 3. 加工步骤

管理材料加工步骤（如：铁锭 → 铁块）。

**功能**：
- 添加加工步骤（名称、描述）
- 编辑/删除加工步骤
- 加工步骤可关联到配方中使用

### 4. 配方管理

管理合成配方，定义物品的制作材料。

**功能**：
- 添加配方（产出物品、产出数量、配方材料列表）
- 支持多层配方（配方A的产出作为配方B的材料）
- 编辑/删除配方
- 每个配方可设置多个材料需求

### 5. 溯源配置

配置材料的溯源关系，实现智能材料统计。

**使用场景**：
例如：配置「铁块 → 铁锭 9个」
- 计算时会自动将铁块转换为铁锭数量
- 显示格式：`9 (包含 1)` 表示需要9个铁锭，其中包含1个铁块

**功能**：
- 添加溯源规则（选择材料、目标材料、数量）
- 批量导入/导出溯源配置
- 溯源信息在计算结果中以不同颜色高亮显示

### 6. 历史记录

保存计算历史，方便追溯和复用。

**功能**：
- 自动保存计算结果（登录用户）
- 查看历史计算详情
- 一键恢复历史计算
- 导出历史记录为CSV

### 7. 用户认证

支持云开发用户认证。

**功能**：
- 邮箱登录
- 登录后可保存计算历史
- 未登录用户可正常使用计算功能，但不会保存历史

## 技术栈

- **前端框架**：React + TypeScript
- **构建工具**：Vite
- **样式**：Tailwind CSS
- **后端服务**：腾讯云开发（CloudBase）
- **用户认证**：CloudBase Auth
- **数据存储**：LocalStorage + CloudBase 数据库
